# Contributing

1. Read `AGENTS.md` and the nested crate instructions.
2. Keep Foundation, Documents, BCF, and bSDD boundaries explicit.
3. Add a failing wire-contract test before changing models.
4. Run `./scripts/gate.sh`.
5. Update README, rustdoc, source evidence, and changelog together when the
   public contract changes.

Do not commit locally licensed standards PDFs or copy upstream schemas without a
verified redistribution license.
