# Local standards corpus

Place locally licensed DIN standards here for research. `*.pdf` is ignored and
must not be committed or packaged. The initial local corpus contains DIN SPEC
91391-1 and DIN SPEC 91391-2 in German and English.

DIN SPEC 91391-2:2019-04 is conceptual prior art. Its scope says implementations
may differ syntactically, and §5.1 says syntactic standardization is deferred to
successor standards. It does not contain or embed a machine-readable OpenAPI
file.
